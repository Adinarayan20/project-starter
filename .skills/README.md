## KEY RULES (Never Violate)

1. `iterative_refinement.md` — Enforce the Draft → Stress-Test → Polish loop on every task.
2. `brand_originality.md` — No generic AI-look patterns. Ever.
3. `mobile_first.md` — Mobile is designed first. Desktop is an enhancement.
4. `security.md` — JWT in HttpOnly cookies only. Never localStorage.
5. `design_system.md` — All colors in HSL CSS custom properties. Never hardcoded hex.
6. `testing_verification.md` — No completion without running tests and checking build.
