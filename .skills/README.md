## KEY RULES (Never Violate)

1. `brand_originality.md` — No generic AI-look patterns. Ever.
2. `mobile_first.md` — Mobile is designed first. Desktop is an enhancement.
3. `security.md` — JWT in HttpOnly cookies only. Never localStorage.
4. `design_system.md` — All colors in HSL CSS custom properties. Never hardcoded hex.
5. `animation_motion.md` — Only animate transform + opacity. Never width/height.
6. `content_copywriting.md` — No AI cliché copy. Specific, human, benefit-first.
