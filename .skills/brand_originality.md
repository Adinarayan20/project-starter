# Antigravity Skill: Brand Originality & Anti-AI-Look System
# Priority: CRITICAL | Impact: 10/10 | Rating: ⭐⭐⭐⭐⭐
# 🆕 NEW SKILL

## ACTIVATION
Load BEFORE any UI design decision on public-facing pages.
This skill exists to ensure no website looks like it was generated by an AI template.

---

## CORE RULE
> If a user can tell it was built by AI, you have failed.
> Every visual decision must feel intentional, human, and unique to this brand.

---

## THE AI-LOOK BLOCKLIST

The following patterns are BANNED. They are the signature of AI-generated, generic, forgettable sites.

### 🚫 BLOCKED COLORS
```
❌ #7c3aed  — generic "AI purple"
❌ #6d28d9  — Tailwind violet-700 as brand color
❌ #4f46e5  — Tailwind indigo-600 as brand color
❌ #0ea5e9  — Tailwind sky-500 as brand color
❌ #1a1a1a  — "cool dark" background (just use brand-specific dark)
❌ #ffffff  — pure white backgrounds (too harsh, use slightly warm/cool off-white)
❌ Using ANY raw Tailwind default color as a brand primary
```

### 🚫 BLOCKED FONTS
```
❌ Inter alone — no personality, used by every AI tool
❌ Roboto alone — Google default, invisible
❌ DM Sans alone — better but still overused
❌ Poppins alone — SaaS template staple
❌ Using only ONE sans-serif font for everything
```

### 🚫 BLOCKED LAYOUTS
```
❌ Hero: Big headline → subtitle → two buttons → product mockup (generic SaaS template)
❌ Three equal-width feature cards with emoji icons in a row
❌ Pricing: Starter / Pro / Enterprise with identical structure
❌ Footer: 4-column links grid (same as every site built in 2020-2024)
❌ Testimonials: 3 cards with star ratings and avatar circles
```

### 🚫 BLOCKED COPY
```
❌ "Empower your [workflow/team/business]"
❌ "Seamless [experience/integration/collaboration]"
❌ "Next-generation [platform/solution/tool]"
❌ "Unlock your [potential/growth/productivity]"
❌ "The [all-in-one / complete / ultimate] solution"
❌ "Get Started" as the only CTA
❌ "Learn More" as a button label
❌ "Trusted by thousands of [users/companies/developers]"
❌ "Industry-leading" without proof
```

### 🚫 BLOCKED VISUAL ELEMENTS
```
❌ Purple/blue gradient blobs as background decoration
❌ Random glassmorphism cards with no purpose
❌ Stock photos of people smiling at laptops or handshaking
❌ Flat emoji used as feature icons (🚀 ⚡ 🎯 💡)
❌ Generic dashboard mockup screenshot as hero image
❌ "Powered by AI" as a selling point
❌ Animated gradient mesh background (overused in 2023-2025)
```

## HOW TO BUILD AN ORIGINAL BRAND

### Step 1: Define Brand Mood (Choose One)
```
Before any design decision, answer: "What should users FEEL when they see this?"

→ WARM & TRUSTWORTHY:    Terracotta, amber, cream, forest green
→ PREMIUM & CONFIDENT:   Midnight navy, warm gold, ivory, black
→ ENERGETIC & BOLD:      Electric coral, deep teal, sand, charcoal
→ CALM & RELIABLE:       Soft sage, dusty blue, warm gray, stone
→ PLAYFUL & CREATIVE:    Hot pink, electric yellow, deep purple, white
→ TECHNICAL & PRECISE:   Cool slate, pure black, electric blue, silver
→ WARM & APPROACHABLE:   Peach, soft yellow, brown, off-white

Document the chosen mood: it guides EVERY decision below.
```

### Step 2: Build Original Color Palette
```css
/* Example: "Premium & Confident" brand */
:root {
  /* Never pick colors from Tailwind defaults */
  /* Build from brand mood using HSL */
  --brand-midnight:  hsl(222, 28%, 12%);   /* Deep navy background */
  --brand-gold:      hsl(38, 85%, 52%);    /* Warm gold accent */
  --brand-ivory:     hsl(48, 30%, 96%);    /* Warm off-white (not pure white) */
  --brand-charcoal:  hsl(215, 18%, 28%);   /* Dark text */
  --brand-smoke:     hsl(215, 12%, 88%);   /* Subtle borders */
}
```

### Step 3: Choose Expressive Typography Pair
```
RULE: One display font for headlines. One body font for text. Always two.

Pairing Guide (choose based on brand mood):
  EDITORIAL/TRUSTWORTHY:
    Display: "Instrument Serif" (serif)
    Body:    "DM Sans" (sans-serif)

  MODERN/TECH:
    Display: "Syne" (geometric sans)
    Body:    "Manrope" (clean sans)

  LUXURY/PREMIUM:
    Display: "Playfair Display" (serif)
    Body:    "Source Sans 3" (humanist sans)

  STARTUP/ENERGETIC:
    Display: "Clash Display" (quirky geometric)
    Body:    "Satoshi" (clean modern)

  WARM/APPROACHABLE:
    Display: "Fraunces" (optical serif)
    Body:    "General Sans" (friendly sans)

  MAGAZINE/EDITORIAL:
    Display: "Cabinet Grotesk" (varied weight)
    Body:    "Lora" (literary serif)

Font Sources:
  https://fonts.google.com
  https://www.fontshare.com (Satoshi, Cabinet Grotesk, Clash Display, etc.)
```

### Step 4: Design a Non-Template Layout
```
RULE: If you've seen this layout on 10 other sites, don't use it.

Techniques for original layouts:
  ✅ Asymmetric hero: text left-aligned, large image breaking out of grid
  ✅ Typographic hero: giant display text AS the visual element
  ✅ Full-bleed photography with text overlay
  ✅ Split-screen layouts with contrasting backgrounds
  ✅ Large typographic numbers as visual anchors (01, 02, 03)
  ✅ Horizontal scroll section for case studies / features
  ✅ Overlapping elements that break the grid intentionally
  ✅ Editorial-style: columns + pull quotes + captions
  ✅ Product-first: screenshot/demo IS the hero (no separate image)
```

### Step 5: Create a Visual Fingerprint
```
Every great brand has signature visual elements unique to them.
Choose 1-2 from this list and use consistently:

  ✅ Custom cursor or cursor glow effect
  ✅ Film grain / noise texture overlay (adds warmth, feels hand-crafted)
  ✅ Brand-specific geometric shape used as a recurring motif
  ✅ Duotone image treatment (photos in brand colors)
  ✅ Oversized typography as decorative element
  ✅ Custom illustration style (even simple geometric shapes are fine)
  ✅ Signature gradient (unique color combination, used sparingly)
  ✅ Horizontal rule / divider style unique to brand
```

## COPY ORIGINALITY RULES

```
BEFORE writing any copy, define:
  1. Who exactly is the user? (specific, not "everyone")
  2. What is the ONE thing they're trying to do?
  3. What's the biggest fear/frustration they have right now?
  4. What's the specific outcome they'll get?

Then write to THAT person about THAT outcome.

Formula for original headlines:
  Specific outcome + timeframe/condition
  "Ship a production API in 4 hours — without writing boilerplate"

  Not: "The ultimate development platform"
  Yes: "The API framework that gets out of your way"

  Not: "Empower your team"
  Yes: "Your team ships on Friday. Not next sprint."

CTA Rules:
  ❌ "Get Started"   →  ✅ "Start Free — No Card Needed"
  ❌ "Learn More"    →  ✅ "See How It Works"
  ❌ "Sign Up"       →  ✅ "Create Your Free Account"
  ❌ "Try It"        →  ✅ "Try It Free for 14 Days"
  ❌ "Contact Us"    →  ✅ "Talk to a Human"
```

## BRAND IDENTITY ARTIFACTS

```
Every brand needs these before any page is built:
  ✅ Color palette (5-7 defined tokens, HSL format)
  ✅ Typography pair + scale
  ✅ Logo (SVG) that works at 24px and 200px
  ✅ Favicon that works at 16px and 512px
  ✅ OG image template (1200×630) for link previews
  ✅ Tone of voice document (3 adjectives: "bold, direct, warm")
  ✅ One-line brand description ("What it is + who it's for")
  ✅ Custom 404 page with brand personality
  ✅ Loading state / skeleton that matches brand colors
```

## FINAL CHECK BEFORE PUBLISHING

Ask these questions about every public page:
```
□ Does this look like a Vercel/Tailwind template? → If yes, redesign
□ Does the color palette feel unique to this brand? → Must say yes
□ Is the font pairing expressive and intentional? → Must say yes
□ Could the headline be on any other site? → If yes, rewrite it
□ Are there any stock photos of people at laptops? → Remove them
□ Does the layout feel fresh or familiar? → Must feel fresh
□ If you hide the logo, can you still tell whose site this is? → Must say yes
□ Does it feel human, or does it feel generated? → Must feel human
```
